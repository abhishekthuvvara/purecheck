# PureCheck

Educational React app about food adulteration in India. Awareness only: home tests are indicative, never conclusive.

## Setup
Requires Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the build
```

## Structure
- `src/data/foods.js` – all content (edit here to add foods/tests)
- `src/components/` – Navbar, Footer, SearchBar, FoodSelector, FoodCard, AdulterantList, RiskAlert, TestGuide, ComparisonCards, ResourceLinks, Disclaimer
- `src/pages/` – Home, FoodDetail, Resources, NotFound

## Content notes
Tests follow widely published FSSAI DART guidance. Please verify the FSSAI links in `foods.js` periodically, and have content reviewed by a food-safety professional before public release.
